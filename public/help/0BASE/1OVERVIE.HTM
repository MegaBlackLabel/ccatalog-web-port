はじめに

このアプリケーションは Windows 環境で動作するコミックマーケットDVD-ROMカタログブラウザです。サークル情報の閲覧、チェック、当日用のオリジナルカタログの印刷を行うことができます。

※ヘルプファイル中の画像ファイルには旧バージョンのものが含まれていることがあります。

動作環境

  • Windows 7/8/10 32/64bit (日本語版以外の動作は保証しません)
  • CPU：800MHz以上 ※OSの必須環境以上
  • 搭載メモリ：512MB以上 ※OSの必須環境以上
  • DVD-ROMドライブ
  • HDDの空き容量：100MB以上
  • SVGA(800×600ドット)以上でHighColor(16ビットカラー)が表示可能なビデオボード

注意事項

DVD-ROMカタログのデータの再配布は許可されていません。圧縮率を変更するなどしたデータなども同様です。カタログページ画像のサークルカットはそれぞれの参加サークルの著作物です。

※「コミックマーケット」「コミケット」「コミケ」は有限会社コミケットの登録商標です。
